# TaskFlow AI

یک اپلیکیشن ساده و کامل برای مدیریت کارهای روزانه — به‌عنوان یک نمونه‌کار
(portfolio project) که مهارت‌های زیر رو نشون می‌ده:

- ساخت یک **REST API** واقعی با Flask
- اتصال به **دیتابیس SQLite**
- ساخت یک **رابط کاربری** ساده و کاربردی با HTML/CSS/JS
- طراحی یک بخش "دستیار هوشمند" که اولویت کارها رو پیشنهاد می‌ده

## اجرای پروژه

```bash
pip install -r requirements.txt
python app.py
```

سپس در مرورگر آدرس زیر رو باز کنید:

```
http://127.0.0.1:5000
```

## ساختار پروژه

```
taskflow-ai/
```

## API Endpoints

| Method | Endpoint             | توضیح                    |
|--------|-----------------------|---------------------------|
| GET    | `/api/tasks`          | دریافت لیست همه‌ی کارها  |
| POST   | `/api/tasks`          | افزودن یک کار جدید       |
| PUT    | `/api/tasks/<id>`     | ویرایش یا تکمیل یک کار   |
| DELETE | `/api/tasks/<id>`     | حذف یک کار               |

## بخش "دستیار هوشمند"

تابع `suggest_priority()` در `app.py` بر اساس کلمات کلیدی موجود در عنوان و
توضیحات کار (مثل «فوری»، «امروز»، «بعداً») یک اولویت پیشنهاد می‌ده. این نسخه
ساده و rule-based هست تا پروژه بدون نیاز به API key اجرا بشه.

**قدم بعدی برای ارتقا:** به‌جای این منطق ساده، می‌شه همین تابع رو به یک
فراخوانی واقعی به یک AI API (مثلاً Claude API) وصل کرد و از مدل خواست که
تسک رو تحلیل و اولویت‌بندی کنه. چون منطق داخل یک تابع جدا (`suggest_priority`)
قرار داره، تغییر «نحوه‌ی» تصمیم‌گیری (rule-based → AI-based) بدون نیاز به
تغییر بقیه‌ی برنامه ممکنه — این یک نمونه‌ی خوب از طراحی تمیز کد هست.

## ایده‌های توسعه بعدی

- اتصال واقعی به یک AI API برای اولویت‌بندی هوشمندتر
- افزودن قابلیت دسته‌بندی کارها (کار، درس، شخصی)
- افزودن تاریخ سررسید و یادآوری
- انتشار روی یک سرویس رایگان مثل Render یا PythonAnywhere
